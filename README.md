# conservation_evidence_factors_synthesis

This repository contains the data and code needed to reproduce the analyses for the article "Factors influencing the use of scientific evidence in conservation practice and policy: insights from a systematic map" published in Journal of Applied Ecology.

You can find the code in the folder "code", data in the folder "data", with separate subfolders for raw and processed data, analysis output in the folder "figures", and the manuscript and associated documents in the folder "docs".
